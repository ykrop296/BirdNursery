# Генетика амадина Гульда — разбор калькулятора gouldianfinches.eu

Источник: <http://www.gouldianfinches.eu/sk/geneticka-kalkulacka/russian/> (онлайн-версия 1.1, автор Leoš Rapant).
Авторские права на изображения: www.amadinagouldove.cz / gouldianfinches.eu (подпись есть на каждом GIF — для коммерческого приложения картинки лучше перерисовать, файлы подходят как референс и placeholder).

## Что где лежит в проекте

- `app/src/main/assets/genetics/images/*.gif` — 110 изображений фенотипов (150×150, GIF), скачаны с `/modul-genetic-calculator/image/`.
- `app/src/main/assets/genetics/genetics.json` — машиночитаемая модель: локусы, аллели, варианты выбора в форме (RU/EN), карта всех 110 изображений с разбором имени файла.
- Этот файл — человекочитаемое описание логики.

## Как устроен сайт-калькулятор

1. HTML-форма (POST на тот же URL), 3 признака × 2 пола:
   - `samec` / `samice` — голова (код из 4 символов);
   - `samec_prsa` / `samice_prsa` — грудь (код из 2 символов);
   - `samec_telo_fialove` / `samice_telo_fialove` — тело (код из 4 символов).
2. Расчёт — **на сервере** (PHP). Клиентского JS-движка нет; JS (`/modul-genetic-calculator/js/popup.js`) содержит только массив `messages[0..109]` — полный каталог имён файлов картинок для тултипов.
3. Результат — две таблицы («Потомки-самцы», «Потомки-самки»): процент, фенотип (голова/грудь/тело), генотип, и индекс картинки `doTooltip(event, N)` → `messages[N]` → GIF.

## Генетическая модель (как реализована на сайте)

Пять локусов, объединённых в 3 визуальных признака. Нотация генотипа в результатах:
самец `X{R,G}; X{R,G}; i, i, P, P, m, m`, самка `X{R,G}; Y; i, i, P, P, m, m` —
т.е. локусы головы (R/b) и тела (G/I) сидят на Z-хромосоме, остальные аутосомные.

### 1. Цвет головы: красный/чёрный — сцеплен с полом (Z)

- Аллели: **R** (красный, доминантный) > **b** (чёрный, рецессивный).
- Самец (ZZ): RR, Rb, bb. Самка (ZW): RY, bY.

### 2. Жёлтая голова — аутосомный рецессивный с эпистазом

- Аллели: i+ (жёлтый) / i− (дикий тип). В кодах формы: `i` = i+, `o` = i−.
- Фенотип «жёлтоголовый» (реально голова оранжевая) проявляется только при **i+i+ И наличии аллеля R**.
- **bb + i+i+** = «чёрноголовый, ген. жёлтоголовый (ЖКК / YTB)» — внешне чёрный, но генетически жёлтый (рецессивный эпистаз).
- i+i− = носитель (сплит), внешне не виден.

### 3. Цвет груди — аутосомный, серия множественных аллелей

- Аллели: **P** (фиолетовая) > **l** (розовая/lilac) > **w** (белая).
- PP, Pl, Pw → фиолетовая; ll, lw → розовая; ww → белая.

### 4. Цвет тела: зелёный/жёлтый — сцеплен с полом, неполное доминирование

- Аллели: **G** (зелёный, дикий тип), **I** (жёлтый).
- Самец (ZZ): GG = зелёный; GI = жёлтый ОФ (один фактор, «зелёный пастельный», EN: Yellow SF / Dilute); II = жёлтый ДФ (два фактора, «золотой», EN: Yellow DF).
- Самка (ZW): GY = зелёная, IY = жёлтая.

### 5. Синее тело (разбавление) — аутосомный рецессивный

- Аллели: m+ (синий) / m− (дикий тип). В кодах формы: `m` = m+, `o` = m−.
- m+m+ в комбинации с локусом 4: GGmm = синий; GImm = синий пастельный ОФ (в таблицах результатов встречается как «серебристый ОФ»); IImm = серебристый ДФ (EN: Silver).
- m+m− = носитель («щеп. синий» / split Blue) — фенотип не меняется, картинка берётся от версии `oo`.

## Кодировка в форме (value → расшифровка)

Голова: `[R|b]{2}[o|i]{2}` для самца (2-й символ может быть `b`), самка — `[R|b]Y[o|i]{2}`.
Примеры: `Rbio` = Rb + i+i− → «красноголовый / чёрноголовый / жёлтоголовый»; `bbii` = ЖКК.

Тело: `[G|I]{2}[o|m]{2}` самец, `[G|I]Y[o|m]{2}` самка. Пример: `GImo` = GI + m+m− → «жёлтый ОФ / щеп. синий».

Полный список вариантов формы (RU + EN) — в `genetics.json` → `form_options`.

## Как считается потомство

Стандартное менделевское скрещивание независимо по каждому локусу; для Z-сцепленных локусов самец даёт Z всем, самка даёт Z сыновьям и W дочерям (поэтому таблицы результатов разделены по полу). Проценты даются **на каждый генотип** (не сгруппированы по фенотипу), сумма = 100%. Подписи фенотипов включают сплиты через «/»: например `Rb i+i−` → «красноголовый/чёрноголовый/жёлтоголовый».

Для воспроизведения в приложении достаточно:
1. Решётка Пеннета по 5 локусам (2 Z-сцепленных с учётом пола, 3 аутосомных).
2. Маппинг генотип → фенотип по правилам выше.
3. Маппинг фенотип → картинка по `genetics.json` → `images`.

## Изображения: соглашение об именах

```
{голова}{грудь}{тело}[-суффикс].gif
голова: RRoo | RRii | bboo | bbii | RYoo | RYii | bYoo | bYii
грудь:  PP | ll | ww
тело:   GGoo | GIoo | IIoo | GGmm | GImm | IImm | GYoo | IYoo | GYmm | IYmm
суффикс: -SF (single factor), -DF (double factor), -pastel, -Z, -SF-Z, -DF-Z
```

Особенности:

- **`-Z`** — альтернативная отрисовка (оттенок) того же генотипа; встречается у жёлтоголовых (ii) и у некоторых жёлтотелых. Часть `-Z`-файлов визуально почти не отличается от базовых.
- **`-pastel`** — то же, что `-SF`, но для груди PP (несогласованность имён на сайте): `RRooPPGIoo-pastel.gif` ↔ `RRoollGIoo-SF.gif`.
- Картинки есть **только для фенотипов** (не для сплитов: Rboo использует картинку RRoo и т.п.).
- **Нет картинок жёлтоголовых (ii) с синим телом (mm)** — сайт такие комбинации не иллюстрирует; в приложении надо дорисовать или брать ближайшую.
- Нет картинок груди Pl/Pw/lw — используются канонические PP/ll/ww.
- Картинки выбираются по фенотипу приблизительно: например «серебристый ОФ» (GI m+m+) на сайте показывает картинку `RRoollIImm-DF.gif` (серебристый ДФ) — при портировании лучше завести точный маппинг.
- Самки визуально отличаются от самцов (приглушённые цвета, белая окантовка) — файлы с `Y` в коде головы.

Всего 110 файлов, ~756 КБ, все проверены (HTTP 200), дубликатов по md5 нет.

## Интеграция в приложении BirdNursery

- `data/model/GouldianGenetics.kt` — движок: варианты генотипов (как в формах сайта), генотип → фенотип → имя картинки (с fallback для жёлтоголовых с синим телом), конвертация кодов при смене пола, `predictOffspring()` — менделевский прогноз потомства с процентами (агрегируется по фенотипу).
- `ui/components/GouldianBirdImage.kt` — загрузка GIF из assets с кэшем.
- В БД (v4) у птицы хранятся `headGenotype` / `breastGenotype` / `bodyGenotype` (старые цветовые Int-колонки удалены пересозданием таблицы в миграции 3→4).
- Прогноз окрасов птенцов показывается на экране добавления птицы, когда выбраны оба родителя.
- Экран «Дерево» (`ui/screens/pedigree/`) — предки/потомки с выгрузкой в PDF через системную печать.
